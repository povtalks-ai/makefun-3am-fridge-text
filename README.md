One line, 101 characters: the text message a smart fridge sends its owner
at 3am. Not about the milk, the ice or a door left open — about the owner
who keeps opening the fridge and taking nothing, so the fridge finally
speaks up about the loneliness they share.

Built for the [make.fun "The 3AM Fridge Text"
bounty](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d),
$2 in USDC to the funniest line.

## The text

> Hey. It's 3am. I counted: you've opened me four times and taken
> nothing. We're both just lonely, huh?

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only, no network) writes the line to
`entry.txt` in the output directory, after checking it is a single line
of 1 to 140 characters.
